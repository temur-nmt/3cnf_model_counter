# HOW TO

This folder has all the files needed for the **OMICS CLUSTER**

* Move everything in the folder in the OMICS Cluster
* Build Benchmarks with the `Makefile` 
* Use `bench_cnf` for comparing the parallel and sequential implementations for **Problem Set A**
* Use `bench_par` for benching the parallel implementaiton for **Problem Set B**


> [!NOTE]  
> Problem Set B has 63 variables. Running it with `bench_cnf` will yeald no results as the sequential algorithm won't finish in your lifetime.
